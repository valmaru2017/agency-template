## Banned AI-Design Clichés
Never use any of these patterns:
- Gradient text on headlines (purple/blue/pink gradients especially)
- Pill-shaped or boxed "eyebrow" badges above the main headline
- Single words in italic or serif inside a sans-serif headline for "elegance"
- Emojis in headings or UI
- Generic 3-column feature cards with icons
- Glassmorphism cards, glow effects, blurred colored blobs in the background
- Centered hero with badge + headline + subtext + two buttons (the default AI layout)
- Purple as default accent color

Instead: create hierarchy with type scale, weight, spacing and layout — not decoration.
Headlines can be left-aligned, oversized, broken across lines intentionally, like editorial design.
